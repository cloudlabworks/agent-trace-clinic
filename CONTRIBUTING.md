# Contributing

Issues and pull requests are welcome: https://github.com/cloudlabworks/agent-trace-clinic

## Before you open a pull request

1. `npm ci`
2. `npm run lint` (ESLint recommended rules; CI fails on any finding)
3. `npm test` (CI runs this on every push and pull request)

## Pull requests

- One change per pull request.
- **New behaviour comes with tests.** A bug fix adds a test that fails without the fix.
- Keep the README in step with any change to inputs, outputs or commands.
- By contributing you agree your work is released under the MIT licence in `LICENSE`.

## Security

Do not open public issues for security problems. See `SECURITY.md`.
