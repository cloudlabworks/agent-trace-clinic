# Security policy

## Reporting a vulnerability

Please report security issues privately to **alex@cloudlabworks.dev**, or use GitHub's
"Report a vulnerability" (private security advisory) on this repository. Do not open a public issue.

Include what you found, how to reproduce it, and the version or commit. You will get an
acknowledgement within 7 days. Fixes are released as a new tagged version, and the advisory
credits the reporter unless you ask otherwise.

## Supported versions

Only the latest release on `main` receives security fixes.

Organization-wide contact: https://cloudlabworks.dev/.well-known/security.txt
